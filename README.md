## 🚀 Getting Started

### Prerequisites

- Flutter SDK `>=3.0.0` — [Install](https://docs.flutter.dev/get-started/install)
- Android Studio or VS Code

### Installation

```bash
# Clone the repo
git clone https://github.com/Ahmed-Moataz-glitch/Ketab-Sawty.git

# Install dependencies
flutter pub get

# Run the app
flutter run
```

### Build

```bash
# Android APK
flutter build apk --release

# iOS
flutter build ios --release
```
